# 活动复盘找茬器 · 活动健康度诊断工具

面向运营人员的**零代码**活动健康度诊断工具。让复盘会从「朗读数据」转变为「决策会议」。

## 解决什么痛点

活动结束后，运营需要拉取转化漏斗数据并对比历史活动，但通常只能「描述现象」而难以「诊断原因」，导致复盘会沦为数据朗读会。本工具自动完成对比、定位与归因，直接产出可执行的改进清单。

## 核心功能

1. **零配置漏斗模板**：内置裂变、秒杀、打卡、抽奖 4 类活动的标准漏斗（曝光 → 点击 → 参与 → 转化 → 分享），选择活动类型即自动匹配指标结构，无需手动配置。
2. **自动对比历史均值**：内置按渠道校准的行业基线库，将当前活动各环节转化率与「同渠道同类型」历史均值对比，计算偏差百分比。
3. **定位卡脖子环节**：偏差超过阈值（低于均值 15%）的环节在漏斗图中高亮标注为「显著下跌」。
4. **原因推测（带置信度）**：结合活动类型特征，从**文案吸引力 / 时机选择 / 门槛设置 / 激励机制**四个维度给出原因推测，每条附置信度。
5. **优先级改进清单**：按**影响 × 难度**双维度排序，标注「⚡ 速赢项（高影响·低难度）」与「🛠 攻坚项（高影响·高难度）」，每条建议明确预期提升方向，支持按优先级筛选。

## 使用方式

1. 选择活动类型 → 选择投放渠道 → 填入各环节实际人次。
2. 点击「开始诊断」，即可查看健康分、漏斗诊断图、原因推测与改进清单。
3. 可点「载入示例数据」快速体验。

## 部署到魔搭创空间（ModelScope Studio）

1. 在魔搭创空间新建创空间，SDK 选择 **Static（静态）**。
2. 将 `index.html` 与本 `README.md` 上传至创空间仓库根目录。
3. README 顶部的 YAML 元信息已配置 `sdk: static` 与 `app_file: index.html`，保存后创空间会自动构建并上线。

> 诊断逻辑基于行业漏斗基线 + 偏差检测，结果为辅助决策参考。基线数据可在 `index.html` 的 `TYPE_BASE` / `CHANNELS` 中按团队实际历史数据自行校准。
